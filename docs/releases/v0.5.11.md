# Codex App Manager v0.5.11

修复 Windows 多安装共存时反复显示「未管理」的问题，并更新依赖。

- **接管当前显示的安装**：同时存在 MSIX 与便携安装，或便携版被上游自行更新后，「开始管理」会刷新界面当前选中安装的记录，避免接管另一个安装导致状态一直无法恢复。
- **显示真实的 Manager 更新进度**：应用自身更新现在显示后端下载和安装进度，并由后端完成重启。
- **改进 Windows 下载**：兼容系统代理设置，并通过系统 TLS 下载链路改善部分网络环境中的连接问题。
- **更新依赖**：整合 13 个依赖更新，同步主程序及独立引擎的 Cargo.lock；CI 使用 --locked 检查，防止依赖检查时偷偷重写锁文件。

## 升级

可在 Manager 中检查更新，或从本页 Assets 下载对应平台安装包。遇到反复「未管理」时，升级 Manager 后再次点击「开始管理」。

便携安装请通过 Manager、开始菜单或 LaunchCodex.exe 启动。直接双击官方 ChatGPT.exe 时的包身份问题继续在 [#370](https://github.com/Wangnov/Codex-App-Manager/issues/370) 跟踪。日志中启动后立即 exit=0 的具体原因仍需受影响机器复测确认。

## 下载

Windows 提供 x64/ARM64 安装器；macOS 提供 Apple Silicon/Intel DMG。latest.json、.sig 和 .app.tar.gz 用于应用内更新，下载后可通过 SHA256SUMS 校验。
